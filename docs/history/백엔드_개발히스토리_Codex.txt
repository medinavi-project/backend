MediNavi 백엔드 개발 히스토리 — 발표자료·Claude 병합용
작성 기준: 2026-11-24 Asia/Seoul

문서 범위와 신뢰도
- CODEX-Hxx는 이 대화에서 진행된 작업 이력이다. 제안·구현·실연동 실패를 구분했다.
- 날짜는 초기 대화 기간 수준의 추정이다. 각 실험의 정확한 시각이나 테스트 로그 원본을 복원한 문서가 아니다.
- 현재 저장소는 이후 추가 수정돼 초기 단계와 구조가 다를 수 있다. 과거 상태를 현재 구현으로 단정하지 않는다.
- 테스트 통과 개수는 각 단계 당시 기록이다. 합산하지 않으며 성능 지표로 제시하지 않는다.
- 의료적 정확성, 실제 환자 안전성, 전체 처방의 병용 안전성 검증 완료를 주장하지 않는다.
- 키·인증 정보는 포함하지 않았다.

발표의 중심 이야기
사진·대화 입력을 외부 AI에 연결하는 기본 서버에서 시작해, 실제 API의 스키마 차이·OCR 오타·불확실한 품목·근거 부족을 발견했다. 이를 API 계약, 상태 관리, 공식 근거, 약별 부분 결과, 회귀 테스트로 분리하며 개선했다. 특정 사례의 성공보다 실패를 식별하고 올바르게 보류하는 구조를 만든 과정이다.

발표 구성 초안 (슬라이드 8장)
1. 목표와 사용자 흐름: 증상 문진 / 사진 한 번의 약품 안내
2. 교체 가능한 AI 연동과 FastAPI·Redis 구조
3. 실제 문진에서 발견한 계약·문맥 손실 문제
4. OCR→약품 검색의 어려움과 문자 유사도 후보 탐색
5. 공식 자료·DUR·AI 요약을 분리한 부분 결과 처리
6. 새 모듈 교체로 생긴 회귀와 수정 전후 비교
7. 사용자 중심 5항목 DTO 및 GHCR→NCP CD
8. 검증 한계·후속 개선과 Claude 작업 통합

발표에 사용할 수 있는 실제 관찰 비교
- OCR 원문 후보: 일반 문구 포함 9개 → 약 이름 표기 5개.
- 해당 샘플 식별: Final 연결 직후 1개 → 회귀 수정 후 2개.
- 해당 샘플 불확실 표기 3개. 서로 다른 표기가 같은 약일 수도 있어 실제 약 개수로 단정하지 않는다.
- 2개 공식 효능 원문 fallback 성공. 이를 AI 자연어 요약 2개 성공이라고 말하지 않는다.
- 타이레놀 단일 실험의 구조화 요약 검증 성공과 복합 입력 검증 보류를 모두 제시한다.
- 범용 인식률/정확도 수치는 측정하지 않았다. 샘플별 결과만 발표한다.

[CODEX-H03] Redis 문진 상태와 중복 요청
기간: 2026-11-20~2026-11-21 (대화 기준 추정; 개별 커밋과 일대일 대응 안 함)
문제: 서버가 이전 대화를 보관하고 동시 요청·재전송에도 턴과 JSON이 중복되지 않아야 했다.
변경: UUID 세션, TTL 1800초, 대화·증상·결과 저장, client_message_id 멱등성, Redis 잠금·Lua 소유권 검사. 동일 ID와 다른 내용은 409. 결과 조회·동일 메시지 재전송은 TTL 미연장.
확인/실험: 실제 임시 Redis로 TTL·만료·동시성·재전송·분석 중 조회·실패 상태 확인. Swagger 기본 UUID 재사용으로 생긴 409를 실세션 메타데이터로 진단.
한계/발표 주의: client_message_id는 프론트에서 메시지별 생성하고 재전송에만 재사용.

[CODEX-H04] Gemini 연결 호환성 수정
기간: 2026-11-20~2026-11-21 (대화 기준 추정; 개별 커밋과 일대일 대응 안 함)
문제: 실제 문진 생성에서 502가 발생했다.
변경: Gemini 전송 스키마에서 additionalProperties를 제거하고 로컬 Pydantic 검증은 유지. 인증·429·타임아웃 등 오류 매핑.
확인/실험: 실제 upstream 400에서 additional_properties 미지원 확인. 이어 gemini-2.5-flash-lite가 신규 사용자에게 미제공이라는 404 확인. 모델 자동 교체는 하지 않음. 이후 실제 연결 성공 기록 존재.
한계/발표 주의: SDK 스키마 호환 오류와 모델 제공 정책 오류는 다른 문제였다.

[CODEX-H06] 증상 분석 범위 재조정
기간: 2026-11-20~2026-11-21 (대화 기준 추정; 개별 커밋과 일대일 대응 안 함)

확인/실험: 가상 사용자 입력을 실제 Gemini로 실행. 3턴 문진과 결과 조회 성공. 다른 입력에서 PRELIMINARY와 의심 질환·진료과 반환 확인.
한계/발표 주의: 실제 환자 진단이나 RAG 근거 검증 완료를 의미하지 않는다.

[CODEX-H07] 문진 종료 기준과 문맥 손실 개선
기간: 2026-11-20~2026-11-21 (대화 기준 추정; 개별 커밋과 일대일 대응 안 함)

확인/실험: 제어된 AI 대역으로 추가 문진·한도·멱등성 확인. 실제 Gemini 결과에 묵직한 느낌이 반영됨. 당시 자동 테스트 30개 통과.
한계/발표 주의: 실제 추가 질문 분기가 모든 실험에서 발생한 것은 아니다.

한계/발표 주의: 후속 Claude 작업에서 문진 엔진이 다시 교체됐으므로 이 단계는 역사적 구조다.

한계/발표 주의: OCR 성공과 최종 약품 안내 성공은 서로 다른 완료 조건.

[CODEX-H11] 제공된 Medicare 의약품 모듈 첫 통합

확인/실험: 실제 CLOVA가 JSON 코드블록과 약품명 키를 반환해 파싱 실패하는 것을 발견·정규화.

[CODEX-H12] 약품 후보 검색과 오인식 분석

[CODEX-H13] 생성 형식과 validator 불일치 해결
기간: 2026-11-20~2026-11-21 (대화 기준 추정; 개별 커밋과 일대일 대응 안 함)

한계/발표 주의: 단일 사례 성공을 모든 사진의 완료로 일반화하지 않는다.

[CODEX-H14] 전체 실패에서 약별 부분 결과로 전환
기간: 2026-11-20~2026-11-21 (대화 기준 추정; 개별 커밋과 일대일 대응 안 함)
문제: 한 약이 미식별이면 다른 약 정보까지 보류되고, DUR unknown이나 부작용 자료 부재가 효능 생성도 막았다.
